# 🌐 Daily Websites

> A collection of compact, everyday life-oriented websites — from birthday greetings, weather forecasts, and music players, to clocks & alarms... Each website provides a delightful experience, created to serve memorable moments in daily life.

## ✨ Introduction

This repository is a collection of **mini-websites** built for personal use and to share with the community. Each project is a standalone website, focusing on a theme related to everyday activities.

**Philosophy:** *Simple — Beautiful — Useful*

## 🚀 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Daily_Websites.git
   ```
2. Open the project folder you want to view.
3. Open the `index.html` file in your browser — that's it! 🎉
